Installing it

  1. Open the downloaded file from your notifications or Downloads.
  2. Android will ask whether to allow installs from your browser. Allow it for that browser only.
  3. Tap Install, then open the app and sign in.

Why it is not on the Play Store

This is an early build, distributed directly while the platform is still being developed. It is signed with a fixed key, so updates install over the previous version rather than asking you to uninstall first.

Nothing in this app files anything with any authority. Every complaint, RTI or application it produces is a draft you send yourself.

Prefer the browser? Use TraceSarkar on the web — it does everything except run in the background.
